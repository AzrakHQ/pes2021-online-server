Check a friend got your exact file Ask your friend to run Get-FileHash .\dinput8.dll in the game folder (Linux: sha256sum dinput8.dll). The result should be: … Capital or small letters and spaces don't matter. That proves the file is exactly the one your server hands out. In the mod's log file (pes2021-online.log), the line key … shows which server it connects to.
What your friend does
  1. In Steam, right-click PES 2021 → Manage → Browse local files, and put the file next to PES2021.exe.
  2. Steam Deck / Linux onlyPES 2021 → Properties → Launch options: WINEDLLOVERRIDES="dinput8=n,b" %command%
  3. Start the game → eFootball → Quick Match → Go to Matchmaking. The first time, they pick a region and a player name.

To stop playing on your server, they just delete the file.

Server commands
  • Show the admin address and password again: sudo docker logs pesserver
  • Stop: sudo docker stop pesserver · Start: sudo docker start pesserver
  • The install command (run it again to update or repair; players, results and friends' mod files keep working):
    curl -fsSL https://raw.githubusercontent.com/MohamedAliRashad/pes2021-private-server/main/install.sh | sh
