What your friend does

  1. In Steam, right-click PES 2021 → Manage → Browse local files, and put the file next to PES2021.exe.
  2. Steam Deck / Linux only: PES 2021 → Properties → Launch options: WINEDLLOVERRIDES="dinput8=n,b" %command%
  3. Start the game → eFootball → Quick Match. The first time, they pick a region and a player name.

To stop playing on your server, they just delete the file.
