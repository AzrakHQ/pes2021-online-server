        Messages

        Talk to your players through the game itself: everyone at once, one player, or a warning before maintenance.

        To everyone

        Shows as a pop-up in the main menu, in Online Information when they sign in, and once in a box before Quick Match.

        Start from:

        Maintenance or restart warning

        Anyone who starts matchmaking gets the game's own warning: "maintenance work starting at [time]… Are you sure you want to start a match now?" Pair it with a message to everyone that says how long it lasts.

        To one player

        They see it in a box the next time they open an online mode, such as Quick Match. The game can't show it sooner. A newer message replaces one they haven't seen. This card shows when they've seen it.

        Download the mod for friends

        One file, dinput8.dll. Send it on Discord, WhatsApp or Telegram; email usually blocks this kind of file.

        Or send this link. It opens a page with the download and the same steps:
        Loading…
        Check a friend got your exact file Ask your friend to run Get-FileHash .\dinput8.dll in the game folder (Linux: sha256sum dinput8.dll). The result should be: … Capital or small letters and spaces don't matter. That proves the file is exactly the one your server hands out. In the mod's log file (pes2021-online.log), the line key … shows which server it connects to.

        What your friend does

        1. In Steam, right-click PES 2021 → Manage → Browse local files, and put the file next to PES2021.exe.
          Steam Deck / Linux: also set PES 2021 → Properties → Launch options to:WINEDLLOVERRIDES="dinput8=n,b" %command%
        2. Start the game → eFootball → Quick Match → Go to Matchmaking. The first time, they pick a region and a player name.

        To stop playing on your server, they just delete the file.
