PES 2021 Server

Your friend's server · …

1. Get the mod (once)

Download the mod

One small file, dinput8.dll, made for this server. It changes nothing outside the game folder (it writes its own small settings and log file there) and nothing in the game's own files, needs no administrator rights, and keeps working after the server restarts.

2. Put it in the game folder

  1. In Steam, right-click eFootball PES 2021 → Manage → Browse local files.
  2. Move dinput8.dll into that folder, next to PES2021.exe.
  3. Steam Deck / Linux only: right-click the game → Properties → Launch options, and paste
    WINEDLLOVERRIDES="dinput8=n,b" %command%

3. Play

  1. Start PES 2021 (version 1.01.00). The first time, pick your region, accept the terms and choose a name.
  2. eFootball → Quick Match → choose a team → Go to Matchmaking.
  3. When two players are searching, the server pairs them. Both press Kick Off.

Good to know

The mod includes MinHook (BSD-2-Clause, © Tsuda Kageyu) and Monocypher (CC0/BSD-2-Clause).

Undo: delete dinput8.dll from the game folder (and the launch option on Linux).
Another server: download the mod from that server's page and replace the file, or hold Shift while the game starts.
Not connecting? The host's server must be running. The mod writes what it tried to pes2021-online.log in the game folder.
Is this the exact file? Its SHA-256 is …. On Windows run Get-FileHash .\dinput8.dll in the game folder (Linux: sha256sum dinput8.dll) and compare. This server's key is …; the mod's log shows it after key.
