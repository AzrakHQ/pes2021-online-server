1. Set up your PC (once)

You need PES 2021 on Steam (version 1.01.00). The game is not modified.

Windows: open PowerShell (Start menu → type powershell) and paste:

irm @@BASE@@/join | iex

Linux / Steam Deck: start the game once from Steam, close it, then in a terminal paste:

curl -fsSL @@BASE@@/join | bash

2. Play

  1. Start PES 2021. The first time, pick your region, accept the terms and choose a name.
  2. Main menu → eFootball → Quick Match. Choose a team → Go to Matchmaking.
  3. When two players are searching, the server pairs them. Both press Kick Off.

Undo

irm @@BASE@@/leave | iex
curl -fsSL @@BASE@@/leave | bash
